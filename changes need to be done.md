The original draft has several scientific issues that must be resolved before journal submission.
1. The claimed 90.7% accuracy and 30-second latency are not supported by the experimental evidence provided.
2. Randomly generated confidence values and boxes produced from image contours cannot be presented as genuine YOLO fracture predictions.
3. A single-class detector cannot reliably classify six different bone types using image coordinates alone.
4. The proposed severity formula is not clinically validated.
5. The dataset source, image count, annotation details, and independent test results are missing.
6. The draft describes both in-memory storage and MySQL, so the actual implementation needs to be confirmed.
